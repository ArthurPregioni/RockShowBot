# Servidor Python independente

O [guia de instalação e hospedagem](../docs/guides/standalone.md) explica configuração, SMTP, Docker, Compose, Render e APIs de música.

Da raiz do repositório, execute `python3 -m selfhosted.rockshowbot` depois de carregar seu `.env`. A configuração de exemplo fica em [`selfhosted/.env.example`](.env.example).

Esta aplicação tem uma interface e um banco próprios. A extensão do navegador e o catálogo ampliado pertencem ao painel Sites; veja a [comparação](../README.md).
